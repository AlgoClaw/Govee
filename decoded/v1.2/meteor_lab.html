H61A8 scene command lab

Load an H61A8 scene, edit its parameter bytes, and rebuild the commands in the same order as the v1.2 Bash generator. Nothing is sent until you explicitly use the local UDP sender.

Experiment controls

The full scene catalog is available through the scene-lab server.

Testing rule: change one byte or one labeled field per scene. Byte 32 is confirmed as Meteor's visible speed control: 00 is very slow and ff is fastest. The inputs labeled “unknown” are intentionally exposed, but their meanings are not yet known.

Send to device

This sends one UDP ptReal JSON datagram containing the generated command array. Browsers cannot send UDP themselves. Open this page through the scene-lab server (the Docker service or node meteor_lab_server.js for standalone development)—do not open this HTML file directly or through another preview server.
